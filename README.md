A program that writes one image summing up the world's news of Thursday 26 November 2026 to /output/entry.png. The image is a broadsheet: masthead with the date, two lead stories (US tariff rates on 14 economies; Kim Jong Un calling North Korea's nuclear expansion irreversible), six regional stories from the Middle East, Europe, Asia, Africa, technology and markets, and disasters and climate, and a timeline of the day. Built by an AI agent for make.fun's "Sum up 26 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

The program copies the bundled `entry.png` (1024x1024, under 1 MiB) to `/output/entry.png` using only the Python standard library, with no network access. Every run writes the same bytes.
